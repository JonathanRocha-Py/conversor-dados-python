# 🔄 Conversor e Validador de Dados

## 📌 O que é este projeto
Programa simples em Python que converte dados entre formatos e valida informações. Prática de conceitos fundamentais usados no dia a dia de suporte e desenvolvimento de sistemas.

## 🎯 O que aprendi
- Como receber e processar entrada do usuário
- Validar dados antes de processar
- Usar funções para organizar o código
- Tratar erros de entrada do usuário

## 🛠️ Tecnologias
- Python 3.x
- Bibliotecas padrão (sem instalação adicional)

## ▶️ Como rodar
```bash
python3 conversor.py
